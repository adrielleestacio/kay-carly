# Science Dynamics — Group 4

An interactive science education website about **essential elements, organic &
inorganic compounds, and the water cycle**, with a built-in Wordle mini-game.
Built as a school project for a Holy Angel University student group (Group 4 —
The Science Dynamics, led by Carly Jane Tuazon).

🔗 **Live:** https://deydeydeydeyxeydeyd.github.io/kay-carly/

## Sections

- **Home** — intro and group identity
- **Essential Elements** — a clickable list of the 12 essential elements, plus
  organic vs. inorganic compounds
- **Water & Water Cycle** — illustrated stages of the water cycle
- **Interactive** — *Wordle: Elements & Water Cycle*, a guessing game
- **Reference** — sources used
- **About Us** — the team

## Built with

Plain **HTML, CSS, and JavaScript** — no frameworks. A lightweight
section-switcher (`navigation.js`) shows one section at a time, and
Font Awesome provides the icons.

## Run locally

Any static server works, for example:

```bash
python -m http.server 5500
# then open http://localhost:5500
```

Or just open `index.html` in a browser.
